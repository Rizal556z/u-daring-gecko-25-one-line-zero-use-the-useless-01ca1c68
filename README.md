## What it does

`main.py` (Python 3.13, pure stdlib, no network) prints exactly one line —
an original, hilariously useless superpower, 144 characters, well within
the 200-character limit:

> My superpower: I can toast any bread perfectly — but only while I'm asleep, so every morning I wake up to the smell of breakfast I'll never eat.

## Run it

```sh
python3 main.py
```
